# Day 03: Loops & Iteration

### What I Learned Today:
- **For Loop**: Best for definite iterations.
- **While Loop**: Ideal when the end condition is dynamic.
- **Do-While**: The "at least once" loop.
- **Break**: Stops the loop immediately.
- **Continue**: Skips the current step and moves to the next.
- **Nested Loops**: Handling multi-dimensional logic.
